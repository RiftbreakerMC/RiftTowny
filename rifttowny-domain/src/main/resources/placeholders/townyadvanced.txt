# The %townyadvanced_*% manifest, baseline towny-papi/2026-08-09.
#
# Captured from the official Towny placeholder reference and recorded in COMPATIBILITY_MATRIX.md
# section 3. This file is the machine-readable copy, and it exists so "complete" can be measured
# against a real list rather than a vague goal.
#
# A test asserts that TownyPlaceholders returns a string - never null - for every name here.
# That is not a formality. Returning null makes PlaceholderAPI leave the literal
# %townyadvanced_whatever% on a player's screen, so an unimplemented placeholder would reach them
# as raw markup rather than as a blank. Blank is a fine answer; markup is a bug report.
#
# Names ending in <n> are parameterised and are tested with several values.
#
# When Towny adds placeholders, the baseline is re-captured, the diff reviewed, and new entries
# added as a new manifest version rather than appended silently.
