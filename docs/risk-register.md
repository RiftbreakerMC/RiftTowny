# RiftTowny — Risk Register

Ordered by expected cost, not by probability. Each risk has an owner action, not just a
description. Reviewed at every phase gate.

| ID | Risk | Impact | Likelihood | Mitigation | Status |
|---|---|---|---|---|---|
| **R-01** | **Installing RiftTowny silently disables 12 sibling integrations.** 54 files across the org reflect on `com.palmergames`. They will not error — they will quietly find no Towny and do nothing | **Critical** — features vanish with no log line pointing at the cause | **Certain** | Native `rifttowny-api` adapters, one PR per repo (INTEGRATION_CONTRACTS §2). Until then, `/rifttowny status` explicitly lists every sibling that is running a dormant Towny bridge, so the cause is visible | Open, mitigated by disclosure |
| **R-02** | **War design churn.** War touches the schema (claims, banks, occupation, scoring). Getting it wrong means a migration against live data | High | Now low | `docs/war-decisions.md` **approved 2026-08-09**, all twelve decisions as recommended, each recording the alternative rejected. The state machine is built transition-as-data so rule tuning is configuration, not schema. Four decisions are load-bearing for the schema and are named in that document as the ones to revisit first | Closed — reopens only if an approved decision is changed after Phase 4 ships |
| **R-03** | **Folia correctness.** A single off-region Bukkit access is a hard crash on Folia and completely invisible on Paper | High | Medium | All Bukkit access via `RiftScheduler`; architecture test forbids `org.bukkit` in `domain`/`storage`; region-scheduled reads for anything positional | Open — see R-07 for the verification gap |
| **R-04** | **Placeholder surface is 150 entries** and blocking on storage during parse would stall the main thread | High | Medium | Snapshot-cache-only resolution, enforced by a test that fails if the expansion can reach a repository. Versioned manifest + golden-output tests | Open, design fixed |
| **R-05** | **Multi-currency ambiguity.** Silently combining or converting currencies is a data-integrity bug that looks like a display bug | High | Medium | Stable currency IDs only; strict resolution order; conversion only via an explicit RiftEco exchange quote; balances never summed across currencies | Open, design fixed |
| **R-06** | **SQLite used on a network.** Two backends on one SQLite file corrupts state in a way that looks like random rollbacks | High | Medium | Startup refuses SQLite when more than one backend is configured. Not a warning — a refusal | Mitigated in Phase 1 |
| **R-07** | **No Folia server and no MariaDB in this workspace.** Folia scheduling and MariaDB migrations cannot be runtime-verified here | Medium | Certain | Contract tests cover the scheduler against a fake platform; migrations are tested on real SQLite. **Folia and MariaDB behaviour will be reported as unverified, never as tested**, until a server is available | Open — needs a target server |
| **R-08** | **No Docker/WSL on this machine** (BIOS SVM disabled), so container-based test harnesses are unavailable | Medium | Certain | Native Maven builds plus jar-descriptor inspection, matching the existing `D:\RiftBreakerSmoke\native` harness | Accepted |
| **R-09** | **Discord channel provisioning does not exist upstream.** VelocitySrv has no channel-creation API | Medium | Certain | Contract defined in INTEGRATION_CONTRACTS §2.6 and marked `BLOCKED`. Commands register but respond honestly. **No fabricated methods** | Open — needs VelocitySrv work |
| **R-10** | **Land regeneration duplicating or destroying items.** Restoring a snapshot over a chest, spawner or shop is a dupe or a loss | High | Medium | Snapshot allowlists; containers, spawners and shop blocks are never restored from snapshot — ownership is handed to RiftShop/RiftSpawners; every restore is RiftLogger-audited; persistent queue so a restart cannot half-apply. **Note:** RiftLogger gained block history and rollback planning on 2026-08-10, so the safety net exists upstream; it is not yet connected, because RiftTowny's adapter and listeners are unwritten. Until they are, the allowlists and the ownership hand-off carry the whole weight | Open, mitigation half-built |
| **R-11** | **Clean-room contamination.** Copying Towny/Lands/TownyFlight code, config, messages or docs | **Critical** — licensing | Low | No restricted source is read, vendored or paraphrased. Only *observable public behaviour* and the public placeholder list are reproduced. WorldDynamics Engine may inform design but **no GPL code is embedded** without explicit licensing approval | Open, policy fixed |
| **R-12** | **Riftspawners is third-party** (SmartSpawner, `github.nighter.*`). Contributing changes upstream has licence implications | Medium | Low | RiftTowny's adapter uses its published API only. Licence checked before any upstream PR | Open |
| **R-13** | **Interface parity slipping.** Bedrock forms are the first thing to be skipped under time pressure, leaving Bedrock players locked out | Medium | High | A parity test enumerates registered actions and fails the build if one lacks a command, chat, GUI or form path | Open — test lands with Phase 2 |
| **R-14** | **Scope.** The brief spans six phases and dozens of subsystems; a half-built core with six half-built advanced modules would be worse than a finished core | High | High | Strict phase gates; advanced modules are optional and must not delay a stable core; `IMPLEMENTATION_PLAN.md` marks partial work honestly rather than optimistically | Open, process fixed |
| **R-15** | **CRLF checkout breaking source-matching tests.** A known org-wide trap that produces unrecognisable errors | Low | Medium | `.gitattributes` pins sources to LF from the first commit | Mitigated |
| **R-16** | **GitHub Packages rejecting the artifact.** Uppercase artifactIds get HTTP 422; already-published release versions get 409 | Low | Medium | artifactIds lowercase from day one; Jenkins deploy stage treats 409 as a no-op and any other failure as fatal | Mitigated |
| **R-17** | **Uncommitted work in two reference clones** (RiftEco, RiftEssentials) could be lost by a careless sweep | Medium | Low | Both left untouched and recorded in INTEGRATION_CONTRACTS §4. No sibling PR is raised until that work is committed or stashed by its author | Open — user action |
